# Avi Town · Первая колония

Изометрический градостроитель про поселение на пустоши. Игрок решает, сколько металла вложить в добычу, а сколько оставить для обороны. После каждого дня НЛО атакуют штаб, добытчики пополняют запасы, и игрок готовится к следующему, более сильному налёту.

## Как запустить

Откройте `project.godot` в Godot 4.6.3 и нажмите F6 из сцены `colony.tscn` или F5 из любой сцены. Для запуска из терминала используйте `godot --path .`.

1. Выберите добытчик или ПВО кнопкой в панели либо клавишами 1 и 2.
2. Щёлкните по свободной клетке. Добытчик стоит 2 металла и даёт +2 к ежедневной добыче. ПВО стоит 3 металла и поглощает 1 урон за налёт.
3. Нажмите Enter или «Завершить день». Сила трёх налётов растёт с 1 до 3 и 5.
4. Сохраните хотя бы 1 прочность штаба после третьего налёта. Esc переключает паузу. «Новая партия» сбрасывает карту, ресурсы и прочность.

## Дизайн прототипа

Цель тестовой партии — 3–5 минут. В первый день хватает металла на добытчик и ПВО, поэтому игрок может сразу увидеть и доход, и эффект обороны. Сила следующего налёта известна заранее. Весь урон сверх общей защиты получает штаб. После победы или поражения доступен перезапуск.

Карта 8×8 отрисовывается в 2D с изометрической проекцией. Тёплые оттенки выделяют добычу, холодные — ПВО, буквы на крышах помогают различать постройки. Графика рисуется кодом проекта. Сторонние графические и звуковые материалы не используются.

Для первой версии выбраны GDScript и Compatibility в Godot 4.6.3. Цель первого запуска — настольный редактор, управление мышью и клавиатурой. Ручной плейтест предстоит. Следующий вопрос для плейтеста — достаточно ли интересен выбор между добычей и обороной, когда сила налётов видна заранее.

## Структура и проверки

- `scenes/colony.tscn` — главная сцена.
- `scripts/colony_rules.gd` — экономика, налёты, состояния партии.
- `scripts/board.gd` — карта, проекция и выбор клетки.
- `scripts/colony.gd` — интерфейс и ввод.
- `tests/smoke.gd` — проверка сцены, строительства мышью, паузы, победы, поражения и перезапуска.

```sh
godot --headless --editor --path . --quit
godot --headless --path . --quit-after 30
godot --headless --path . --script tests/smoke.gd
```

## Запуск в браузере

Игра выполняется в браузере. GitHub Pages раздаёт статические файлы, поэтому для этой версии отдельный сервер симуляции не нужен.

1. Отправьте исходники в ветку `main`.
2. В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. В **Actions → Publish Godot Web to GitHub Pages** нажмите **Run workflow** и выберите `main`. После этого новые коммиты в `main` автоматически запускают сборку и публикацию.
4. После успешного шага **Deploy to GitHub Pages** откройте ссылку из результата публикации.

Для ручного экспорта установите шаблоны экспорта Godot 4.6.3 через **Editor → Manage Export Templates**. Затем выберите **Project → Export → Web → Export Project** и сохраните под именем `index.html` в отдельной папке. Загрузите все файлы из папки на статический HTTPS-хостинг, сохраняя имена и расположение файлов.

Проверка локального экспорта через HTTP:

```sh
mkdir -p build/web
godot --headless --editor --path . --import
godot --headless --path . --export-release Web build/web/index.html
python3 -m http.server 8000 --bind 127.0.0.1 --directory build/web
```

Откройте http://127.0.0.1:8000/ в браузере с WebGL 2.0. В пресете отключены потоки, поэтому веб-серверу не нужны специальные заголовки для SharedArrayBuffer.

### Визуальный референс

Штаб, двухствольная ПВО и дорога с переходом перерисованы в изометрии
по дневной панораме Avi Town 2.0 (`first_contact_day_panorama.png`).
Геометрия отрисовывается кодом. Панорама не включена в дистрибутив.
Дорога находится на стартовой карте, её клетки заняты для строительства.
